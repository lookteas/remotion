# 八字一样的人，命运也会一样吗？ · 动画文字说明脚本

## 版本与确认范围

- 版本：v0.3；更新日期：2026-10-19。标题及采用《运气的形状》参考风格已由用户指定；本轮细化视觉与动效方案，尚未编码、未生成本期样片。
- 发布标题：**八字一样的人，命运也会一样吗？**
- 封面提案：**八字一样 / 就会同命？**；首屏直接提出标题问题，不另做片名卡。封面措辞尚未单独确认。
- 主线：八字记录什么 → 为什么不能据此断定同命 → 感到准确的可能解释 → 怎样检验预测 → 回答标题。
- 核心结论：**不能仅凭八字相同，就断定命运相同。** 方法句：事后能解释，不等于事前能预测。
- 受众：没有命理或统计学基础、在手机上静音观看的普通观众。
- 目录：`videos/data-analysis/01-bazi-prediction/`；计划ID：`data-analysis-bazi-prediction-vertical`，尚未注册。

## 论证与来源核查

1. S02的历法定义已于2026-10-19重新读取[香港天文台《天干地支》](https://www.hko.gov.hk/tc/gts/time/stemsandbranches.htm)正文：年、月、日、时的干支合成八字。此来源不支持命运预测或特定同八字人口数。
2. 讨论同八字时采用一致排盘口径，不把“时辰相同”当作完整八字相同。本片不用具体排盘、未经核实人数、双胞胎个案或一上一下轨迹充当实证。
3. “记不下全部经历”描述时间记号的信息范围，不断言出生季节与任何结果都不相关。两人经历不同也不能直接否定所有概率预测，因此保留S04。
4. 话术与记忆段是演示性的可能解释；不把一段宽泛话术或一次记忆偏差，包装成八字预测无效的实验结论。本次搜索服务403，APA词典页面未取得可核对释义，因此不据此加入心理学术语或声称完成文献综述。
5. 退款为虚构可判定示例，非真实预测，也不是八字的典型断语。对象甲，记录时点起连续七天；命中按退款已到账判定，申请、审核中、仅口头承诺不算。示例不实际展示钱到账，避免误以为已经验证。
6. “不看八字的预测”指预先约定的比较基准，面向相同对象、事件和时段，其他可用信息尽量一致；可依据事件本来的发生率，不能挑一个故意很弱的随机猜法比较。
7. 多次检验需在结果前固定对象、样本、事件、期限、判定和比较方式，命中与落空都记录，避免事后挑选、改口或只保留有利案例；还需在新案例重复。动画仅讲方法，未进行实验、不展示胜率。
8. 不使用19/24比特、人体电磁、面相健康等旧支线；不宣称片长或标题保证抖音推荐。
