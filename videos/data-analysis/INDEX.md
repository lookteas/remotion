# 数据分析科普

用真实数据、图表和指标体系，讲清一个现象是怎么被量化出来的，以及数字背后容易被忽略的口径与陷阱。

- 目录：`videos/data-analysis/`
- Composition 前缀：`data-analysis-`
- 默认画幅：1920×1080 / 30fps，竖版另注册 `-vertical`

## 收录范围

**适合**：数据可视化、统计概念、指标解读、图表误读、行业数据现象、数据来源辨析。

**不适合**：软件操作教程（归 `ai-tools`）、没有数据支撑的观点评论。

## 数据与图表约定

- 每个数据结论必须标注来源、统计口径与年份，写在该期 `ANIMATION.md`，画面角落标注。
- 图表用 SVG / React 组件绘制，不要用截图：保证高清、可换主题色、数字可改。
- 同一组数据在多期复用，优先沉淀到 `src/components/charts/`。
