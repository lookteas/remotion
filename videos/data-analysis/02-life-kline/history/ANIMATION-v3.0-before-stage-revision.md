## 主题、规格和声音

- 正式主题：**如果你的人生上市，你敢抄底自己吗？**
- 要解释的一件事：低谷时，把时间和资源投回身体、技能和生活缓冲，让自己有能力面对下一次选择。“抄底自己”具体指这种自我投入。
- 1080×1920 / 30fps / 2520帧 / 84秒；由本轮表达安排得出，非新时长上限。
- 入口：index.tsx → ListingWorld.tsx。Composition ID：data-analysis-life-kline-vertical。
- 无口播、旁白、配音或TTS。仅4处低音量原创动作音效。
- 发布时在抖音添加《千年之后（氛围版）》；不下载、不嵌入音乐，不声称完成平台配乐或卡点。
- 默认参考：根references/luck-shape/source.mp4及REFERENCE.md；本轮同时查看28.5秒与108秒关键帧，核对暖金、米白、暗底和物件演示风格。未完整实时播放参考原片，不宣称声音或节奏复刻。

## 上屏文案与连续分镜

### K01 · 0—209帧 / 0—7秒

- 文案：“如果你的人生上市，”“你敢抄底自己吗？”
- 首帧已有一段真实形态的蜡烛图；14根历史柱作为上下文，追加柱逐步下行至当前低点。至少包含多个涨跌、实体和上下影线，不用独立方块代表整幅K线。
- 图内标签：“人生K线”“外在处境 · 情境示意”“过去”“时间”；下行过程出现“收入中断”“自我怀疑”，当前落点标“现在”，右方保留“未来未写”。
- 下一镜继承同一批K线与当前落点，不清空图表。

### K02 · 210—419帧 / 7—14秒

- 核心文案：“你以为的绝境，只是周期的筑底。”
- 解释：“处境跌了，不代表你失去了全部价值。”对照标签：“低价 ≠ 低价值”。
- 250帧后，整幅图沿原位置逐步压缩到上方，为具体解释留出空间。图表标签单独排布，不把字体随纵轴压扁。
- 不画确认见底标志、未来上涨柱或反弹预测；“筑底”为用户主题修辞。

### K03 · 420—629帧 / 14—21秒

- 文案：“真正的抄底，是优化底层基本面。”“把时间和资源，重新投给自己。”
- 上方仍是同一幅K线。下方“时间 / 精力 / 资源”三枚投入筹码向同一行动位置汇合，接入睡眠和运动的演示。
- 这里先明确“抄底自己”的意思；后面三项是行动例子，不再以维修结构解释人。

### K04 · 630—989帧 / 21—33秒

- 文案：“身体”“先把自己养回来。”辅助句：“按时睡觉，规律运动。先让自己有精力。”
- 枕头、月亮表示按时睡觉；鞋履连续迈步表示规律运动；完成记录逐次留下。结果标签“精力恢复”。
- 955帧起，同一组物件向左下方缩移并持续保留，给练习腾出中央位置，不突然换页。

### K05 · 990—1349帧 / 33—45秒

- 文案：“技能”“把练习，变成作品。”辅助句：“练到能解决一个问题，拿出一个结果。”
- 稿纸上逐行写下练习，笔沿文字移动。练习叠稿中出现一份可读的“作品”，上有“解决一个问题 / 做出一个结果”，完成后留下成果标记。
- 1310帧起，练习与作品缩到中下方；左侧精力已保留，上方行情没有因写出作品自动上涨。

### K06 · 1350—1769帧 / 45—59秒

- 文案：“现金流”“给自己留一笔备用金。”辅助句：“收入中断时，仍有时间调整、学习和选择。”
- 实体钱包标“生活备用金”，留下一部分收入形成储备；钱币从钱包支付“必要支出：房租 · 吃饭”。
- 1680帧收入暂停，此后两次支出继续消耗留存；不是只堆钱，也不是技能成果自动变成钱币。
- 钱币加入/移出与库存使用同一事件表；3份初始＋8次流入－4次支出＝7份最终留存。停流时9份，此后降至7份。内部计数不作为金额、统计数据或收益展示。
- 同一钱包缩到右下方，保留已消耗的状态。三项是无外框的实际行动结果，不是三张独立机壳卡片。

### K07 · 1770—2189帧 / 59—73秒

- 核心文案：“机会来时，你接得住吗？”
- 一封来信展开，明确题头“新项目邀请”；内容“需要有人：持续投入，把事情做完”，条件“精力 / 作品 / 时间余地”，落款“接不接，由你决定”。
- 下方仍是前面形成的精力、作品和备用金，逐次对应要求；“备用金 → 时间余地”说明资金缓冲与选择空间的关系，不让观众猜。
- 辅助句：“精力、作品、备用金，让你多一点选择的底气。”
- 不表现为基本面会吸引或保证机会；只是示意“如果机会此时出现，准备能带来什么”。未演示接单、收入或成功。

### K08 · 2190—2519帧 / 73—84秒

- 开头：“行情仍在低位，你已经开始积累。”
- 来信移出焦点，原图逐渐放大；同一根当前柱、原历史走势仍在低位，未来留白。
- 同一批精力、作品与消耗后的备用金仍在下方；标清“仍在低位，也能开始投入自己”。
- 最后：“你，愿意抄底 / 自己的人生吗？”保留超过5秒完整阅读时间。
- 结尾的问题已经被前面具体行动解释：是否愿意在低谷继续投给自己，而不是询问能否修好一台机器。
