# 坐北朝南：从太阳高度角看采光

用几何把"坐北朝南"这句老话拆开：避开风水式解释，直接讲清太阳高度角、正午方位、进深三者的关系。

- Composition ID：`traditional-culture-zuo-bei-chao-nan`
- 时长：2180 帧 / 30fps ≈ 72.7 秒
- 画幅：1920×1080
- 状态：制作中

## 受众

参加工作多年、有家庭有事业的职场人与中老年观众。他们关心的是买房、装修、老人孩子住得舒不舒服，而不是物理公式。因此：

- 术语只用一个「太阳高度角」，其余全部用"光能照多深"这类日常说法。
- 每个结论都落到"看房时能用来判断什么"，不做纯知识展示。
- 字号偏大、每屏信息量克制，照顾手机与小屏观看。

## 核心逻辑

1. 悬念：都说朝南好，可东西朝向也能晒到太阳，为什么偏偏是南？
2. 方位：中国大部分地区，正午太阳始终在正南方向 → 南窗对准了太阳最高的位置。
3. 定义：太阳高度角 = 光线与地面的夹角。角度越小，光越平，射得越深。
4. 对比：夏至约 73.5°，冬至约 26.6°（以北纬 40° 估算）。
5. 落点：同一扇窗，冬至光进约 4.8 米，夏至约 0.7 米。
6. 结论：坐北朝南是顺应太阳角度，不是吉凶。
7. 实用：楼间距、窗顶高度、西晒三个看房要点。

## 数据与假设

- 纬度按**北纬 40°（北京）**估算，正午太阳高度角 = 90° − |纬度 − 太阳赤纬|。
  - 夏至赤纬 +23.44° → 73.4°
  - 冬至赤纬 −23.44° → 26.6°
- 窗台离地 **1.0 米**，窗上沿离地 **2.4 米**（层高约 2.9 米时的常见值）。
- 进深按"窗上沿光线落到地面"计算：`进深 = 窗上沿高度 / tan(高度角)`。
  - 冬至：2.4 / tan(26.6°) ≈ 4.8 m
  - 夏至：2.4 / tan(73.4°) ≈ 0.7 m
- 未考虑窗框遮挡、玻璃折射、地面反射、楼间距与地形遮挡，属于简化模型。片中用"约"字标注。
